### B2 mandatory next implementation (single owned public-media pipeline)

**B2 groundwork committed with this update (source only):**
- `app/Domain/Media/MediaIptcXmpWriter.php` builds standard IPTC/XMP ExifTool mappings from the **existing** canonical `MediaRightsProjection` and stages JPEG/PNG/WebP into an **exclusive new file**, never modifying the archived original. Source copyright is not copied as a false photograph ownership claim when an external photo rights holder is named with only the general inherited artwork notice. No guessed creator/owner.
- Mappings: `XMP-dc:Creator`, `XMP-plus:CopyrightOwnerName`, `XMP-photoshop:Credit`, `XMP-dc:Rights`, `XMP-xmpRights:UsageTerms`, `XMP-plus:LicensorURL`. **Do not** equate the contact/license inquiry URL with a verified `WebStatement`. The controlled `XMP-plus:DataMining` tag gets ExifTool's documented value `Prohibited except for search engine indexing` **only on explicit authorization** from the rights owner/publication flow (not automatically on any public file).
- Writer uses shell-free Symfony Process, checks source MIME/length/SHA-256 against the authoritative MediaAsset, refuses overwriting existing staging paths or incomplete copies, attempts to remove known GPS and camera serial tags **in the staged copy only**, checks image dimensions and returns staged SHA-256/size. It has no effect on public media until a separate owner integrates it. **Must still verify** real metadata readback, complete privacy metadata, ICC profile/pixel equivalence, double rights/conflicting source claims, and failure behavior using actual images. Drafted pure unit tests `tests/Unit/Media/MediaIptcXmpWriterTest.php` are **not run**.
- **Toolchain blocker:** Debian Bookworm (current `Dockerfile`) supplies ExifTool **12.57**; IPTC Data Mining needs **>=12.67**. The runtime image currently includes **no ExifTool**. Do not install the Bookworm package expecting it to support this. Select/pin/test a supported version for both local-preview and production builds. Offline writer accepts `MEDIA_EXIFTOOL_BINARY` via `config/media.php` and explicitly fails below 12.67. No Dockerfile or server/deploy change yet.

**Present pipeline:** `MediaIngestService` stores original bytes under `originals/<uuid>.<ext>` with SHA-256, creates GD WebP thumbnail `variants/<uuid>-thumbnail.webp` up to 960px. `PublicMediaController` returns archived original or thumbnail using `X-Sendfile`, SHA-based ETag, `Cache-Control: public, max-age=31536000, immutable`; public access is gated by `PublicMedia::isPublicAsset/isPublicVariant`. There is no IPTC/XMP injection today.

**Architecture to implement safely:**
1. Preserve archived originals **byte-for-byte** and their hash. Do NOT edit `originals/` in place. Assess JPEG/PNG/WebP/GD, audio/video applicability, media quotas, immutable cache and current snapshot/undo/deletion architecture before writing.
2. Introduce one versioned **public artifact** per deliverable (full-resolution public equivalent preserving decoded pixels/ICC as accurately as metadata editing allows, plus current intended 960px WebP thumbnail); **write known rights tags and clear sensitive GPS/serial metadata** without silently deleting third-party license grants. Use supported ExifTool/IPTC-XMP with actual bytes read back, or a demonstrated format-correct writer. New generated variants/keys/ETags must change atomically when rights metadata changes; fixed immutable cache URLs must not serve stale rights data. No parallel galleries/CDNs/timer/polling.
3. Existing media needs bounded, safely restartable backfill; General inherited notice changes also affect descendants, including public/committed reference correctness. Publication commits/preview, cache, Snapshot/Undo and deletion must remain consistent. No hidden cost explosion; check storage quota.
4. IPTC = International Press Telecommunications Council photo rights vocabulary; XMP = Extensible Metadata Platform, format to embed tags. Map actual ExifTool-compatible XMP/IPTC fields: `Creator`, `CopyrightNotice`, `CopyrightOwner`, `CreditLine`, `RightsUsageTerms`, `WebStatementOfRights`; machine-readable IPTC/PLUS `DataMining` option `DMI-PROHIBITED-EXCEPTSEARCHENGINEINDEXING` if actual rights holder can reserve those uses. Validate **actual standard identifiers** rather than using ad-hoc readable strings as tag values. Metadata cannot stop byte copying.
5. For public SEO, publish only genuinely valid `ImageObject` `creator`, `creditText`, `copyrightNotice`, `license`/ `acquireLicensePage` mapped from same resolver; no auto-created open license, no false photographer ownership. Preserve Google indexing, alt text and existing page metadata. Never display a new visible © line on Artwork detail.
6. Tests must verify independent metadata extraction on both full-resolution file and thumbnail; archive SHA unchanged; pixel dimensions/ICC preserved; inherited/explicit-none/third-party terms correct; no GPS; changed authoring rights produce new public URL+ETag; bytes served through X-Sendfile with original access authorization unchanged; rollback/publication/preview/noop; old URL cache semantics.
