## Added

### Application and public foundations
- **Core stack:** Adopted Laravel, Filament and PostgreSQL with defined public/admin architecture and domain ownership ([#7](https://github.com/Wiiii90/moeller-lars/issues/7), [#8](https://github.com/Wiiii90/moeller-lars/issues/8)).
- **Gallery:** Implemented artwork category listings and explicit ordering ([#11](https://github.com/Wiiii90/moeller-lars/issues/11)).
- **Home:** Implemented latest-artwork selection ([#12](https://github.com/Wiiii90/moeller-lars/issues/12)).
- **Media delivery:** Added original-image and thumbnail delivery ([#13](https://github.com/Wiiii90/moeller-lars/issues/13)).
- **Artwork editing:** Defined the Artwork/Media editorial data model and created the initial artwork editor ([#17](https://github.com/Wiiii90/moeller-lars/issues/17), [#18](https://github.com/Wiiii90/moeller-lars/issues/18)).
- **Media ingestion:** Added controlled uploads and derivative generation, preserving source originals ([#19](https://github.com/Wiiii90/moeller-lars/issues/19)).
- **Editorial models:** Introduced initial Biography/CV and Exhibition records and Blog Post persistence with stable slugs; subsequent milestones introduced the complete user-facing workflows ([#22](https://github.com/Wiiii90/moeller-lars/issues/22), [#26](https://github.com/Wiiii90/moeller-lars/issues/26)).
