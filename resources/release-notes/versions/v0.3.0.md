## Added

### Public site and editorial content
- **Routes and navigation:** Introduced canonical public routing and the replacement navigation/site shell.
- **Pages:** Added typed Site Sections and a unified Pages workspace for Home, Gallery, Journal, Custom Pages and structural navigation.
- **Gallery:** Added Gallery-centric artwork editing and canonical Gallery placement controls in Pages.
- **Nested navigation:** Added hierarchical artwork categories and dropdown navigation.
- **Biography/CV:** Added its editor and public display (subsequently normalized to Custom Page composition).
- **Exhibitions:** Added editing and public display of exhibitions.
- **Contact:** Introduced public contact delivery and abuse controls.

### Admin workspaces, insight and recovery
- **Dashboard:** Introduced the shared overview and Storage/Activity/Analytics entry points.
- **Quick actions:** Added context-aware, per-user dashboard shortcuts.
- **Media library:** Completed Files editorial actions and reusable asset inspection.
- **Gallery editor:** Added additional batch/media-first workflows and per-artwork analytics to the gallery workspace.
- **Activity:** Added the administrative action history and activity insights.
- **Undo:** Added conflict-aware selective undo for supported editorial and media/lifecycle mutations, including explicit receipts.
- **Artwork analytics:** Added per-Artwork attention reporting and stable attention identifiers.
- **General:** Completed site-wide identity, contact information and general editorial settings.

## Changed
- **Editorial workspaces:** Consolidated separate model-oriented tables into integrated editors.
- **Site structure:** Removed hardcoded content semantics and moved navigation/site hierarchy to the canonical Site Section owner.
- **Rich Text:** Introduced controlled Markdown/rich-text and safe external-link handling.
- **Admin layout:** Consolidated dialog/control geometry and shared UI behavior.

## Fixed
- Corrected leading separators and gallery-sequence rendering in public Artwork presentation.
- Improved thumbnail usage, image delivery and perceived loading behavior.
- Reduced administrative interaction latency and established a performance budget.

## Internal
- Added the legacy Artwork/media importer and normalized source accounting.
- Consolidated the test suite and its verification workflow.
- Established the deployable immutable application artifact contract.
