A meaningful test guards observable behavior, authorization, publication Working vs Committed, mutation notification/audit/no-op, rollback or stable domain data. Never bypass this guard on an existing local preview or production DB. BrowserProfilingSeeder has the same protection.
- Mark each conclusion SOURCE-REVIEWED, TEST-AUTHORED, TEST-RUN or BROWSER-VERIFIED accurately. Update this living file in the same commit as substantive testing changes. Replace obsolete status and priorities rather than accumulating another dated work log.
