**Branch:** `dev`

## Current ownership and accepted user decisions
- All Admin dialog categories remain native Filament Actions via `app/Filament/Support/Dialogs/AdminDialog.php`. Single shared presentation owners: `resources/js/admin-dialog-geometry.js`, `resources/css/admin/dialog-contract.css`, and shared admin controls. Never replace Filament's close, focus/Escape, validation/autosave, stacking/backdrop or scroll-lock lifecycle; no per-page dialog geometry.
- On desktop with fine pointer, dragging the dialog's header and Alt+arrow keys on its focused header move the native window. Header actions, close button, fields and links retain their own interactions. Mouse-only touch/mobile returns to fixed native responsive presentation.
- **New user decision (2026-11-20): Remove manual dialog resizing completely.** Delete grip, manual width/height CSS, resize keyboard handler and associated JS. Resizing the browser viewport must still re-clamp a deliberately moved window.
- Add a restrained, subtly tinted title bar with a single 1px horizontal bottom border spanning the entire header, including the contextual action region. This visually separates heading/controls from dialog content without an extra parallel header.
- **Critical correction:** After the first drag/resize implementation, user observed dialogs initially opening far right, mostly outside the screen. Before that feature, opening within the centered content frame worked. Preserve the exact pre-drag Filament window geometry for every untouched dialog. Do not apply position:relative, drag coordinates or corrective clamping on initial mount when the window may be unpainted.

## Current source change — native starting frame plus deliberate drag
- Rebuilt the geometric extension on top of the already accepted **pre-drag** `resources/js/admin-dialog-geometry.js` and `dialog-contract.css` (baseline `dev@5aa48a4`). The original frame CSS and shared `x-modal-opened` measurement remain authoritative for initial alignment. Removed previous global window `position:relative; left/top` override and all manual resizing code/styles.
- The existing geometry controller stores a per-open-modal offset **only after a deliberate move**. It activates a scoped CSS `translate` on that window, preserving Filament's separate transform-based native enter/leave animation. No default moved-state or speculative correction is set during modal mounting, so pre-paint zero dimensions cannot add hundreds of pixels of erroneous displacement.
- The same measured post-Sidebar Main and topbar bounds constrain pointer and keyboard movement. On viewport changes and Livewire morph updates, reapply and clamp **only already moved** dialogs. Closing a dialog or navigating away discards the move; reopening uses Filament's original centered size and location.
- Header action exclusion and fine-pointer-only drag keep Edit autosave, action controls, native scroll and nested popovers independent. No new package, extra scroll lock, confirmation, modal family, domain schema, public scripts, test or documentation change.
- The shared `dialog-contract.css` header is now slightly tinted using existing Admin surface tokens and has a full-width bottom border. The accepted top-right header action buttons, corner radii, size presets and confirmation semantics are unchanged.

## Other active constraints and status

User observed major practical improvement in Admin dialog opening and overall responsiveness. Rich Text insertion, General favicon, long search, Edit autosave, Repeater selections and keyboard interaction still need browser acceptance.
