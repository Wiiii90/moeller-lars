## Required invariants (user-approved 2026-11-03)
1. Working artist content, registered originals and every required available thumbnail/poster stay coherent through upload, linking, reuse, delete and recovery. **Registered but unassigned media is legitimate**, not a zombie.
2. A **true zombie** is a physical media file with no Working, Committed, retained-history, deletion-outbox or active-upload owner. Logically deleted files retained for legitimately protected Activity/Publication do NOT count as zombies; Activity/Undo will be intentionally cleared before release, not used as an excuse for permanent architecture.
3. **Free Storage never destroys required thumbnails**, never triggers libvips from an HTTP request, and only removes eligible former restore/Undo data, explicitly deleted media and proven orphaned/stale staging.
4. A single authoritative thumbnail reader/writer; no permanent pre-release `public-v1`/`public-v2` variants or on-request regeneration. Preserve persisted artist data and any genuine Committed/recovery ownership until a controlled data cutover proves safe.
5. Preserve deliberately generous upload and image-size requirements. No arbitrary new general file/pixel cap. Cross-filesystem+PostgreSQL completion must be durably reconciled rather than falsely claimed physically atomic.
6. Only the Testing worker authors/executes regression tests on `testing`. Dev Worker 2 records **grouped** acceptance work here, not per-commit test files.
