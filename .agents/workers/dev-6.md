## Current Home implementation

- **Hero source ownership:** `HomeHeroConfigurationService` owns the single persisted `artwork.source_profiles` map. Automatic, Semi-Automatic and Manual retain independent Strategy, rotation and source configuration. Automatic uses published eligible Galleries only; Semi-Automatic combines eligible Galleries with its own `Manual Sourced Artworks` group; Manual has an entirely separate candidate group. Source switching restores each saved profile rather than overwriting it. Gallery selection, candidate ordering, sourced/random chances, media eligibility and public rotation use existing domain/resolver owners, not another Stage store.
- **Hero source table:** Four columns (Gallery, Candidates, Actions, Selection), central responsive action/selection geometry, independently horizontal-scrollable candidate thumbnails, status and Artwork ratio controls removed. Add Candidate is hidden completely in Automatic; both remaining entry points share the canonical Storage picker in Semi-Automatic/Manual.
- **Home content templates:** Under Construction and Custom have independently saved editor state and share the canonical Custom Page component forms, media controls, validation/conversion, nested Image children, Contact, List and Rich Text behavior. Published editorial content and destructive dependencies remain protected by existing domain checks and auditable notifications; no second Home-specific component persistence path exists.
- **Stage source update in this commit:** Exact half-width visual/rail split at wide geometry; responsive stacking; central gold Admin kicker and four compact quick settings (Source, Rule, Size and Strategy, hiding inapplicable fields); the canonical gold heading is followed in all strategies by explicit `Preview:` and `Next Rotation:` labels; Sequential displays human-readable UTC calendar dates, Random accurately labels its 10-second Stage simulation, and Top Only reports no rotation. Candidate count and explanatory status under the editors remain removed; fixed six-track candidate rows with Position, reorder handle for stored Manual members in both applicable modes, image/info, Chance and inline Actions; existing publish/unpublish/delete/move icon catalog reused. Current simulated image has contextual actions for the active typed candidate. Automatic and Semi-Automatic now support saved individual automatic Artwork exclusions. Each stored Manual member has an independent enabled flag; disabled items remain listed, retain their media reference, order and relative weight, and are excluded from the public resolver until re-enabled. Remove still deletes only the group membership. The canonical settings service, audit and AdminNotifier remain the only mutation/feedback owners.

## Current Gallery candidate accordion (latest feature slice)

- The Home source table still uses its one canonical four-column header. Every Gallery and the virtual Manual Sourced Artworks row now has a keyboard-accessible Candidates toggle: collapsed thumbnails remain horizontally scrollable, with a mouse-drag threshold to prevent an accidental toggle; expanded candidates become a vertically stacked full-width detail row with Name, effective Random Chance and individual enable/disable actions. Only Manual candidates additionally have Remove, which removes just their saved membership. Gallery automatic exclusions remain visible with Enable for restoration, and Manual disabled items remain in the list. The source table projects existing Stage candidate/weight rows; it does not create a parallel selection or chance model.

When expanded, group actions are hidden while individual candidate actions are shown; expanded detail has no Position or reorder actions.

Removed an obsolete Home viewport rule in Responsive that contradicted the accepted candidate-first narrow Stage. Narrow group-actions retain both icon axes; no horizontal table scrolling has been added.
