# Dev Worker 3 — Admin Dashboard

- **Branch:** `dev`
- **Lease:** 25
- **Assignment:** Dashboard Notification readability, sequential-group actions, and Activity presentation of repeated edits.
- **Current state (2026-11-20):** Source-corrected the nonfunctional group actions. The original group row emitted Blade `@json(...)` inside component attributes; all four actions now use the same literal notification key pattern as working individual actions, and the server resolves membership from the current visible group. Every group member remains one individual record and is touched at most once. Mixed read/unread groups choose Mark all read until all messages are read; Pin all delegates to idempotent `DashboardFeedPins::pinMany()`. Existing pinned priority rows remain independent.
- **Notification details:** `DashboardFeed::projectNotification()` resolves the Audit relation for both paginated and individually opened records, projects actual before/after field summaries, and removes duplicated narrative only when it matches the canonical Audit details. `AdminActivityPresentation::notificationHeadline()` now uses concise object/field wording without repeating the resulting value. Historical old detailed titles are adjusted only in read projection when exactly recognized. The existing detail viewer and a shared Blade change-fields partial present before/after values in both single and group dialogs.
- **Delete confirmation:** All existing Dashboard delete confirmations display the central `AdminControl::checkbox('delete_without_confirmation')`, which persists the user's Dashboard preference only after the confirmed delete. Cancel retains the prior preference. Direct deletion when already enabled is unchanged.
- **Invariants:** No synthetic group records, no extra deletions through multi-selection; underlying Activity/Audit and Notification records are preserved until existing per-entry deletion/retention rules apply. No schema, migration, new notification storage or parallel dialog family.
- **Verification:** Code-path/read-back checks passed for dispatch, group identity, read/pin/delete, checkbox, and structured display. PHP/database runtime, browser interaction and automated tests were not executed; this remains a source implementation awaiting acceptance.
- **Relevant paths:** `app/Filament/Pages/Dashboard.php`, `app/Domain/Admin/{DashboardFeed,AdminActivityPresentation}.php`, Dashboard feed table/dialog and `dashboard-feed-changes.blade.php`, local Dashboard CSS. Activity visual grouping remains as previously implemented.
