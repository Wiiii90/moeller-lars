# Contributing

This repository is currently maintained as a project-specific application and is **not accepting external code contributions or pull requests**.

The source is public for transparency, review and project visibility, but no open-source license is granted at this time. Public visibility does not grant permission to copy, redistribute, modify or commercially reuse the code beyond rights provided by applicable law.

## Issues

Public issues may be used for non-sensitive bug reports or project discussion when appropriate.

Do **not** report vulnerabilities, credentials, private data or reproducible exploit details in a public issue. Follow [SECURITY.md](SECURITY.md) for security reports.

## Future contribution policy

If the project later opens to external contributors, this file will be replaced with explicit contribution, licensing and authorship terms before contributions are accepted.
